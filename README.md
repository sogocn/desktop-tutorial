# 家庭任务日历

家长给孩子派任务、孩子自建任务；任务以日历形式展示；奖励分三类（打卡奖励 / 任务完成奖励 / 任务完成阶段奖励）。
**本地优先**：数据存在每台设备的浏览器里（PGlite 浏览器内 Postgres + IndexedDB），不上传任何服务器。

> 当前阶段（M1）：纯本地版，用于功能验收。部署到阿里云等环境**待本地测试通过后再做**（见文末「部署」）。

## 技术栈

- 前端：React 19 + TypeScript + Vite 7 + Tailwind v4（移动端优先，手写日历不引库）
- 数据：PGlite（浏览器内 WASM Postgres），IndexedDB 持久化，约 3MB 懒加载
- 状态：Zustand（persist）+ TanStack React Query
- 测试：SQL 断言先行（`scripts/run-sql-tests.mjs`），目前 117 项全绿

## 本地运行

```bash
npm install
npm run dev          # 打开 http://localhost:5173
```

首次进入会走引导页：建一个家庭，或拿邀请码加入。建好后数据就落在当前浏览器，
关掉再打开、刷新都还在；换设备需先「导出备份」再导入。

## 本地测试清单（验收用）

在浏览器里逐条走一遍：

1. `npm run dev` 打开即用，无需任何账号；刷新后数据仍在。
2. 引导页：能「建家庭」也能「加入家庭」（拿另一个浏览器的邀请码）。
3. 家长建任务：六种排期（单日 / 截止日 / 每日 / 工作日 / 每周 / 每月）都能选，奖励分打卡分与完成分。
4. 孩子能自建任务，但打卡分 + 完成分合计受上限卡控；孩子不能给别人派活。
5. 今天页：今日任务 + 进度条；打卡 / 完成 / 撤销 / 请假都生效；完成高分任务有撒花+震动。
6. 日历月视图：每天圆点、全完成显 ✓；未来日期不可操作（防刷分）。
7. 钱包页：积分明细（含打卡/完成/阶段/兑换/退回）、勋章、商城兑换。
8. 商城兑换：现金类即时成交；需审批的进 pending。
9. 家长 PIN：设置 / 修改；审批兑换时要先输 PIN。
10. 我页：邀请码复制、家长切看不同孩子、导出备份、退出身份、清空数据。
11. 控制台无报错（尤其迁移、RLS、`request.jwt.claims` 相关）。

逻辑层另跑：`npm run db:test`（SQL 117 项断言，覆盖展开引擎 / 排期校验 / 记账 / 商城等）。

## 构建

```bash
npm run build        # tsc -b && vite build → dist/
npm run preview      # 本地预览 dist/
```

## 数据位置与备份

- 库落在浏览器 IndexedDB，库名 `familyquest`（对应 `idb://familyquest`）。
- 「我 → 数据 → 导出备份」下载整库 `.tar.gz`，换设备可带走。
- 「清空所有数据」会删除该 IndexedDB 库并刷新页面（不可恢复，建议先备份）。

## 部署（待本地验收通过后）

当前是纯静态 SPA + 浏览器内数据库，**部署 = 把 `dist/` 当静态文件托管**，无需后端：

- 最省事：对象存储（OSS）+ CDN，或任意静态托管。
- 内网/自托管：一台小机器跑 nginx 反代 `dist/` 即可（2 核 2G 远超所需）。
- 多设备云同步（让不同手机看到同一份数据）属于后续阶段（M2+），需要独立的 Postgres，
  不在本次本地版范围。届时复用 `db/migrations/*.sql` 同一份 DDL，前端零改动换 adapter 即可。
